# Library Management System

A RESTful Library Management System built using Spring Boot.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Gradle
- REST API
- Swagger / OpenAPI

## Features

- Book management
- Patron management
- CRUD operations
- Borrowing and returning books
- Database persistence
- RESTful APIs
- Swagger API documentation

## API Documentation

Swagger UI:
http://localhost:8081/api/swagger-ui/index.html

## Database

MySQL database is used for persistent data storage.

## How to Run

1. Clone the repository
2. Configure MySQL
3. Update database credentials
4. Run:

```bash
./gradlew bootRun
